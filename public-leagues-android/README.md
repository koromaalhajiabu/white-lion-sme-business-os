# White Lion Public Leagues Android APK

Standalone Android application for the Public Leagues Directory:
https://koromaalhajiabu.github.io/white-lion-sme-business-os/public-leagues.html

GitHub Actions builds a debug-signed, directly installable APK. The APK is provided as a workflow artifact for testing and direct distribution. It is not signed with a Play Store production key.

Application ID: com.whitelion.publicleagues
