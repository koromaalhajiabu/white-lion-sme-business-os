Android installation:
1. Open this page in Chrome.
2. Tap the three-dot menu.
3. Choose Install app or Add to Home screen.
4. Confirm and launch White Lion SME from your apps list.

If Chrome says it is already installed, open the existing White Lion SME icon instead of creating another shortcut.
